# RaftCore

**Web apps** (Chrome or Edge, nothing to install - see [Raft Web Apps](https://github.com/robdobsn/RaftCore/wiki/RaftWebApps)):
- [Device Types](https://robdobsn.github.io/RaftCore/devtypes/app/): browse the device type catalogue, and build and push a device's type file
- [Raft Flasher](https://robdobsn.github.io/RaftCore/flash/): flash a Raft build to an ESP32 over USB

Raft is an async-first, opinionated app framework for the development of embedded applications.

Currently Raft supports the Espressif ESP32 family.

[Please see the Raft documentation](https://github.com/robdobsn/RaftCore/wiki)
